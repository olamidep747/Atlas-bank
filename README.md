# ATLAS Bank

A fresh, mobile-first digital banking brand and homepage built with Next.js, TypeScript, and Tailwind CSS.

## Brand system
- Deep navy: `#0A1F44`
- Electric blue: `#0066FF`
- Gold: `#FFD84D`
- Off-white: `#F8FAFC`

## Run locally
```bash
npm install
npm run dev
```

## Deploy
Import this repository into Vercel and use the default Next.js build settings.

## Important
The current site is a visual brand and homepage foundation. It does not provide real accounts, deposits, transfers, cards, or other regulated banking services. Authentication and any live financial functionality must be securely implemented and tested before launch.
